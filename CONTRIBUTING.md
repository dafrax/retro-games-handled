# Contributing

Thank you for improving the retro gaming notes.

## Before Opening a Pull Request

- Test instructions on the stated device or software version when possible.
- Explain what was tested and what was not tested.
- Use small, focused commits.
- Remove personal paths, credentials, and identifying data.
- Add rollback or recovery instructions for system changes.

## Pull Request Description

Include:

- Problem or use case
- Device and version
- Summary of the change
- Verification performed
- Known limitations

Documentation corrections and reproducible troubleshooting steps are welcome.
