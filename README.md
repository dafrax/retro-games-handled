# Retro Games Handled

Notes, guides, configurations, and troubleshooting for retro gaming devices and emulation systems.

## Repository Contents

- `tools/` — setup and configuration guides for common tools
- Device-specific notes and troubleshooting steps
- Reproducible configuration examples

## Documentation Principles

- Record the device model and firmware/version where relevant.
- Prefer reversible configuration changes.
- Include backup and rollback steps before changing storage or system files.
- Never publish private keys, personal access tokens, or personal data.

## Contributing Notes

When adding a guide, include:

1. The target device or operating system.
2. Required hardware, software, and versions.
3. Installation or configuration steps.
4. Verification steps.
5. Recovery or rollback instructions.
6. Known limitations.

## Safety

Back up saves, configuration files, and storage images before making changes. Commands that modify disks or firmware must be checked against the target device before execution.
